# Phase 1: the iOS shell — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Passionate Learning runs as a real iOS app (Capacitor 8) on the iPhone and the iPhone Duo, fully offline, with the P1 audit fixes, ready to upload to TestFlight the moment the App Store Connect app record exists.

**Architecture:** The Next.js 16 static export in `app/out` becomes Capacitor's `webDir`; nothing loads from the network. Audit fixes land in the web code, so the website gets them too. A thin `src/lib/native.ts` is the only place that knows whether it is running inside the app.

**Tech Stack:** Next.js 16 (static export; read `app/AGENTS.md` and `node_modules/next/dist/docs/` before touching routing), React 19, TypeScript strict, Tailwind v4, vitest 4, @playwright/test 1.63, Capacitor 8.6 (`@capacitor/core`, `cli`, `ios`, `haptics`, `app`, `splash-screen`, `status-bar`), Xcode 27.2.

**Spec:** `docs/superpowers/specs/2026-11-06-app-store-v2-design.md` (phase P1, the audit table rows 6, 8, 15 and the "Broken now" paragraph, and the red-team section).

## Global Constraints

- App ID `ca.stiersolutions.passionatelearning`; display name `Passionate`; minimum iOS 17; version `1.3.0`, build `1`.
- `ITSAppUsesNonExemptEncryption` = `false` in Info.plist.
- Fully offline: no remote URL in `capacitor.config.ts`, no `server.url`, no runtime fetch of code or content.
- "No streak guilt": no copy anywhere that threatens loss. Days played only counts up.
- House look stays: white paper, ink `#0a0a0a`, accent `#ff3b1f`, Archivo Black / Archivo / Patrick Hand / JetBrains Mono, the stickman from `src/art/Stick.tsx`.
- No placeholders or "coming soon" rows in shipped screens. Account settings arrive in P3, not as stubs now.
- `prefers-reduced-motion` and the new Motion setting are both respected.
- Save stays `v: 1` in this phase (Save v2 is P2); new settings fields are added with defaults in `sanitize`, never a version bump.
- Commit only files this plan names, by path; never `git add -A`.

## Review Focus

1. **Cold start on a non-root route inside the app** (iOS kills the app mid-round, or a link opens `/w/prompt/`): Capacitor's iOS asset handler serves the ROOT `index.html` for extension-less paths, so the wrong page can render. Expect the right page every time. Pinned in Task 8 (simulator deep-load check, with the fix in Task 6 if it fails).
2. **An old save missing the new settings fields, or one with junk in them:** expect defaults, never a crash. Pinned in Task 3.
3. **A stored in-progress round that is stale (older than 30 minutes), for another unit, or corrupt:** expect a fresh round, never a crash or a wrong card. Pinned in Task 4.
4. **Long words and memes at 430 and 669 wide:** expect no horizontal page scroll anywhere and the feedback drawer never covering an option. Pinned in Task 5.
5. **A locked unit opened by direct URL on a brand-new save:** expect the locked screen naming what to finish first, never a playable round. Pinned in Task 2.
